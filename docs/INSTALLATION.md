# Installation Guide

## System Requirements
- Windows 10/11 (64-bit)
- 4 GB RAM minimum
- 500 MB disk space

## How to Install

1. Download the latest version from our website
2. Double-click: `Luxury Jewellers Setup 1.0.0.exe`
3. Follow the installer wizard
4. Click "Finish" when done
5. The app will open automatically
