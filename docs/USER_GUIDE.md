# User Guide

## Getting Started (First Time)

1. **Configure Your Shop**
   - Go to Settings → Shop Profile
   - Enter your shop name and GSTIN
   - Add address and contact details

2. **Set Today's Rates**
   - Go to Rate Master
   - Enter gold/silver/platinum rates for today

3. **Create Your First Invoice**
   - Click Billing → New Invoice
   - Search for an item
   - Adjust quantity, making charge if needed
   - Click Complete Sale
   - Print the PDF invoice

## Key Features

### Billing
- Fast invoice creation
- Automatic GST calculation
- Professional PDF printing
- Old-gold credit support

### Inventory
- Track all items with weight & purity
- Real-time stock levels
- HUID/hallmark support

### Reports
- Sales register
- GST summary for filing
- Stock valuation
- Customer/supplier dues

### Backups
- One-click backup to USB or cloud
- Settings → Backup & Restore

## Common Tasks

**How to add a new customer?**
- Customers → New Customer → Fill details

**How to record a purchase?**
- Suppliers & Purchases → New Purchase Bill

**How to process old gold trade-in?**
- Old Gold → New Exchange → Enter purity and weight
